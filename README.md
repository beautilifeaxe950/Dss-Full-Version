## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Dual Playback Decks** — Mix tracks from two compatible playback decks supporting MP3, WAV, OGG, and more.
- **CUE Points** — Utilize 8 CUE points for precise control and seamless transitions between tracks.
- **Scratch and Search Modes** — Choose between scratch or search modes for tailored mixing experiences.
- **Native DSP Effects** — Enhance your mixes with built-in DSP effects and the ability to add VST or DirectX plugins.
- **Beat Grid Synchronization** — Achieve perfect song synchronization with advanced beat grid functionality.

### Advanced Features:
- **MIDI Device Compatibility** — Control DSS with any standard MIDI device for enhanced mixing flexibility.
- **Oversampling Options** — Improve audio quality during playback with oversampling settings.
- **ASIO and WDM Driver Support** — Ensure compatibility with a wide range of audio interfaces for optimal performance.
